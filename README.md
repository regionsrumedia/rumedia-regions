# PWA «Регионы Румедиа»

Готовая оболочка для установки на Samsung/Android с собственной иконкой.

Рабочее приложение:
https://script.google.com/macros/s/AKfycbyHVQJJhuI26fzBS0yJeV7aJOz67eGpiWsRjHfq0D17AjC0hC7XHF1-oU63kZX0Mj8/exec

## Содержимое

- index.html — страница установки и запуска
- manifest.webmanifest — описание PWA
- sw.js — service worker
- icon-192.png — обычная иконка 192×192
- icon-512.png — обычная иконка 512×512
- icon-maskable-192.png — адаптивная иконка 192×192
- icon-maskable-512.png — адаптивная иконка 512×512
- apple-touch-icon.png — дополнительная иконка 180×180
- .nojekyll — отключает обработку Jekyll на GitHub Pages

## Размещение на GitHub Pages

1. Создайте бесплатный аккаунт на GitHub, если его нет.
2. Нажмите New repository.
3. Назовите репозиторий, например: rumedia-regions.
4. Выберите Public. Для GitHub Free Pages из обычного репозитория он должен быть публичным.
5. Создайте репозиторий.
6. Нажмите Add file → Upload files.
7. Загрузите ВСЕ файлы из этой папки именно в корень репозитория.
8. Нажмите Commit changes.
9. Откройте Settings → Pages.
10. В разделе Build and deployment:
    Source: Deploy from a branch
    Branch: main
    Folder: /(root)
11. Нажмите Save.
12. Подождите несколько минут. GitHub покажет адрес вида:
    https://ВАШ-ЛОГИН.github.io/rumedia-regions/

## Установка на Samsung

ВАЖНО: сначала удалите старые ярлыки «Регионы Румедиа», на которых виден маленький значок Chrome/Яндекс.

### Через Samsung Internet
1. Откройте GitHub Pages адрес PWA именно в Samsung Internet.
2. Подождите 5–10 секунд после первой загрузки.
3. Используйте предложение браузера установить приложение либо пункт установки PWA в меню.
4. Подтвердите «Установить» / «Добавить на экран приложений».
5. На рабочем столе должен появиться самостоятельный значок Румедиа без маленького значка браузера.

### Через Chrome
1. Откройте GitHub Pages адрес PWA в Chrome.
2. Меню ⋮ → «Установить приложение».
3. Не выбирайте вариант, который создаёт обычный интернет-ярлык.
4. Подтвердите установку.

## Как это работает

При обычном открытии GitHub Pages показывается установочная страница.
При запуске уже установленной PWA с рабочего стола она автоматически переходит
в рабочее приложение Google Apps Script.

Примечание: рабочее приложение находится на другом домене (script.google.com).
Поэтому после запуска Android-браузер в некоторых версиях может показать
небольшую системную панель с адресом Google. Это НЕ маленький значок браузера
на ярлыке: сама иконка на рабочем столе остаётся собственной PWA-иконкой.

## Если Samsung всё равно показывает значок браузера

Это почти всегда означает, что создан обычный ярлык, а не установлена PWA.
Удалите его и повторите установку, выбрав именно «Установить приложение»
или установку PWA / на экран приложений.
